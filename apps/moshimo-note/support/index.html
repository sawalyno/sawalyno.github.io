もしもノート

家族に伝える記録 — もしもの時に家族が迷わないために

アプリについて

もしもノートは、万が一の際に家族が知っておくべき重要情報をスマートフォンにローカル保存するエンディングノートアプリです。

銀行口座・保険・デジタルアカウントのパスワードなど、11カテゴリの情報を一か所にまとめて記録できます。データはすべてお使いの端末内にのみ保存され、クラウドサーバーへの送信は一切行いません。

  • 11カテゴリ対応（金融資産・保険・デジタル資産など）
  • 「デジタル資産・アカウント」は無料。買い切り¥800で全11カテゴリ解放
  • カスタムカテゴリ作成（自作カテゴリ・項目を自由に追加）
  • パスワード付きPDFで、家族と安全に共有
  • アプリを開くたびに顔認証・指紋認証などで本人確認
  • データはすべて端末の中にだけ保存（インターネットに送られません）
  • iOS / Android 両対応

よくあるご質問

アプリのデータはどこに保存されますか？
入力したすべてのデータはお使いの端末内にのみ保存されます。クラウドサーバーへの送信は一切行いません。アプリを削除するとデータも消去されますのでご注意ください。
生体認証を設定するにはどうすればよいですか？
もしもノートはアプリ起動時に毎回、端末に設定された生体認証（Face ID・Touch ID・指紋認証）または端末パスコードで認証を行います。特別な設定は不要です。
端末に生体認証が設定されていない場合は、端末のパスコードが代わりに使用されます。端末の「設定」から生体認証をあらかじめ登録されることをおすすめします。
無料版と買い切り版の違いは何ですか？
無料版では「デジタル資産・アカウント」カテゴリの記録と、その内容のパスワード付きPDF出力をご利用いただけます。
買い切り版（¥800・一度払えば永久利用）では、残り10カテゴリ（金融資産 / 保険 / 本人・緊急情報 / 不動産・住まい / 車 / 借金・ローン / 緊急連絡先・専門家 / 本人の意思・希望 / ペット / 遺言・相続）と、全カテゴリ入りのパスワード付きPDF出力・カスタムカテゴリ作成機能が解放されます。
PDF出力機能の使い方を教えてください
下部タブの「PDF出力」からご利用いただけます（無料版は「デジタル資産・アカウント」のみ、買い切り版は全カテゴリを出力します）。パスワードを設定し、安全な取り扱いに関する同意事項（5項目）を確認の上、出力ボタンをタップしてください。
生成したPDFはAirDrop・メールなどスマートフォンの共有機能で家族に送ることができます。パスワードはPDFとは別の手段（口頭・別メッセージなど）で家族に伝えてください。
別の端末で購入を復元するには？
アプリ内の買い切りアンロック画面にある「購入を復元する」をタップしてください。
iPhone: 同じApple IDでサインインしている場合、以前の購入が復元されます。
Android: 同じGoogleアカウントでサインインしている場合、以前の購入が復元されます。
データのバックアップはできますか？
現在のバージョンでは、データのエクスポート・バックアップ機能は非対応です。端末の紛失・初期化・アプリの削除によってデータが消えた場合の復元はできませんのでご注意ください。
PDF出力機能を使用してパスワード付きPDFを保存しておくことで、記録の控えとしてご活用いただけます。
カスタムカテゴリを追加するには？
買い切り版の購入後、アプリ内のカスタムカテゴリ作成画面からご利用いただけます。カテゴリ名・アイコンを設定し、項目を自由に追加してオリジナルのエンディングノートを作成できます。
